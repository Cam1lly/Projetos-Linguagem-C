#  Desenvolvimento de Algoritmos em Linguagem C

Repositório dedicado ao estudo de lógica de programação de baixo nível utilizando a Linguagem C. 
Aqui estão reunidos os projetos e exercícios estruturados desenvolvidos durante a minha trajetória técnica e acadêmica.

---

## Estrutura e Organização das Pastas

Os códigos estão organizados de forma semântica de acordo com os conceitos de estrutura de dados e complexidade algorítmica:

*   **`Linha e Coluna (Matrizes)/`**: Estruturas de dados bidimensionais organizadas em linhas e colunas, com foco em manipulação de tabelas, coordenadas e matrizes numéricas.
*   **`Funções/`**: Modularização de código, escopo de variáveis e passagem de parâmetros para a criação de sistemas mais organizados e reutilizáveis.
*   **`Ponteiros/`**: Práticas avançadas envolvendo manipulação direta de endereços de memória e referências de variáveis.
*   **`Outros/`**: Mais algumas atividades para testar o conhecimento e a lógica de progração.
